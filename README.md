## Installation

Copy the `.dll` and `.pdb` to TrafficMonitor's `plugins/` directory.

## Usage

Requires LX Music running with Web API enabled (default port `23330`).

Configure via plugin options dialog:
- **Port** — LX Music Web API port
- **Font / Size / Scroll Speed** — lyric display settings
- **Width** — `0` for auto-width
